# 🌐 Dafin Orvala Aprillo • Portofolio Siswa | SMK Telkom Malang

Portofolio web resmi **Dafin Orvala Aprillo**, siswa **SMK Telkom Malang** jurusan **Teknik Komputer dan Jaringan (TKJ)** serta **Desainer Grafis & Video Editor**. Website dirancang dengan tata bahasa Indonesia yang santun dan profesional, gradasi warna cyan-ungu yang bersih dan elegan, foto profil muka, kartu deskripsi diri, galeri dokumentasi mobil modifikasi, banner 16:9, serta tautan media sosial resmi.
